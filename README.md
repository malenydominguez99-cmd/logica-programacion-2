# Conversor de Temperaturas

## Descripción

Ejercicio práctico desarrollado con HTML, CSS y JavaScript que permite convertir una temperatura ingresada en grados Celsius a Fahrenheit y Kelvin.

El usuario introduce un valor numérico y el programa realiza las conversiones, mostrando los resultados en la página web.

## Objetivo

Aplicar fundamentos de lógica de programación mediante operaciones matemáticas, validación de datos y manipulación de elementos HTML con JavaScript.

## Contexto

Ejercicio académico realizado durante mi formación en **Generation México**, como parte de las actividades prácticas de programación.

## Pasos realizados

1. Crear la estructura de la página utilizando HTML5.
2. Diseñar un formulario para ingresar la temperatura en grados Celsius.
3. Aplicar estilos visuales con CSS.
4. Capturar el evento de envío del formulario mediante JavaScript.
5. Validar que el usuario ingrese un valor numérico.
6. Convertir el valor ingresado a tipo numérico.
7. Aplicar las fórmulas de conversión:
   - Fahrenheit: (C × 9/5) + 32
   - Kelvin: C + 273.15
8. Mostrar los resultados directamente en la página web.

## Resultado

Se desarrolló un conversor de temperaturas que permite ingresar grados Celsius y obtener sus equivalencias en Fahrenheit y Kelvin.

También se incorporó una validación básica para mostrar un mensaje cuando el usuario no ingresa un número válido.

## Aprendizajes

- Fundamentos de JavaScript.
- Declaración y uso de variables.
- Conversión de datos mediante `Number()`.
- Validación de entradas con `isNaN()`.
- Manejo de eventos con `addEventListener()`.
- Manipulación del DOM.
- Uso de `textContent` para mostrar resultados.
- Aplicación de operaciones matemáticas.
- Estructuración de formularios con HTML.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
